# ⚔️ 王者荣耀 3D - 手机触屏对战游戏 (Mobile MOBA)

基于 **Three.js (3D Low-Poly) + 原生触屏双轮盘 + Node.js WebSocket** 打造的手机端王者荣耀 1v1 对战游戏。

---

## 🌟 核心特性

1. **手机端全功能双轮盘触控系统**：
   * **左侧浮动虚拟摇杆**：360° 灵敏走位，手指任意触碰左屏自适应吸附。
   * **右侧技能轮盘**：普攻大按键 + 1/2/3 技能按键。按下手指拖拽即可呼出 **3D 地面投影指示器**（直线箭头、扇形、圆形范围、锁定光圈），松手释放；滑向右上角红色警告区取消施法；单击自动锁敌施法。
   * **功能按键**：回城（4.5秒引导传送）、恢复（回血血包）、终结（真实伤害斩杀）、技能升级加点（`+`）。
2. **三大经典首发英雄**：
   * 🛡️ **亚瑟（战士/坦克）**：圣光回血被动、1技能誓约之盾（加速跃斩沉默）、2技能回旋打击（圣盾旋转持续AOE）、3技能圣剑裁决（高空跳斩范围击飞斩杀）。
   * 🦊 **妲己（法师/爆发）**：法穿削减被动、1技能灵魂冲击（直线贯穿法术波）、2技能偶像魅力（爱心追踪眩晕1.5秒）、3技能女王崇拜（5团连续追踪狐火）。
   * 🏹 **后羿（射手/持续）**：攻速多重箭被动、1技能炙热之风（强化分裂攻击）、2技能落日余晖（天降日光范围减速）、3技能灼日之矢（全图飞行烈焰神鸟巨箭，远距离巨额眩晕）。
3. **经典墨家机关道推塔竞技**：
   * 双方基地泉水、外防御塔（仇恨保护、越塔报警与递增激光伤害）、核心水晶基地。
   * 周期性兵线刷新（近战步兵与远程法师小兵）。
   * 1~15 级局内升级体系，击杀小兵/英雄获得金币与经验。
   * 快捷神装商城：抵抗之靴、暗影战斧、无尽战刃、回响之杖、博学者之怒、不祥征兆。
4. **双对战模式**：
   * 🤖 **单人训练（对抗智能电脑 AI）**：随时单人开局，AI 具备补刀对线、技能连招、残血撤退、防塔意识与自动出装。
   * ⚔️ **双人 1v1 实时联机**：支持输入 4 位房间码或快速匹配，两台手机同台竞技。
5. **视听与打击反馈**：
   * Web Audio API 程序化纯本地合成音效（刀剑挥斩、弓矢破空、法术轰鸣、防御塔警告、击杀号角）。
   * 3D 世界到屏幕投影的彩色伤害飘字（物理红字、法术紫字、暴击金字、生命绿字）。
   * 实时雷达小地图与击杀横幅播报（First Blood、击败敌方英雄、胜利/失败）。
6. **即开即玩与手机扫码**：
   * 服务启动时终端自动侦测局域网 IP 并生成 **ASCII 二维码**，同一 Wi-Fi 下手机相机扫码即可秒进游戏，无需下载 App。

## 🚀 启动运行

### 1. 启动本地游戏服务器
```bash
npm start
# 或直接运行：
node server.js
```

### 2. 访问方式
* **手机端**：确保手机与电脑连接同一 Wi-Fi，用手机扫码终端显示的二维码（或在手机浏览器输入 `http://<你的局域网IP>:5001`），将手机横屏即可畅玩。
* **电脑端调试**：浏览器访问 `http://localhost:5001`。
  * 电脑端键盘控制支持：
    * `W / A / S / D`：英雄走位
    * `J` 或 `空格`：普通攻击
    * `U / I / O`：释放 1 / 2 / 3 技能
    * `B`：回城
    * `F`：恢复
    * `D`：召唤师技能（终结）
